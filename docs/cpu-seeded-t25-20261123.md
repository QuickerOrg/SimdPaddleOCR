## 实现与边界

新增 `Experimental/MatMul.ArgMax.SeededAvx.cs`，复制固定版本的AVX2矩阵乘主体，仅替换收尾。前16类正常计算，选行最大值与最小胜出索引，广播最大值作为8个lane共同下界。每个lane的初始分母只包含自己负责的两个真实项，不重复添加种子winner。

后续每个8项向量，仅当所有值严格小于各lane当前最大值减25时跳过原Update256。保留原ExpCore、FMA顺序、在线重缩放、最终归约、标量列尾及最小索引平局规则。没有引入历史位置依赖、Top-K或更低精度指数。

仅支持.NET10、AVX2且无AVX512、原packed gate通过、rows为4倍数的形状；其它情况回原实现。首tile出现非有限值时整个调用回原算法，保留原异常语义。多unit按原AVX2 MergeKind=2的连续布局合并。原型显式开关为 `SIMD_OCR_EXPERIMENT_CPU_SEEDED_T25=1`，不设置即关闭；只在隔离实验子进程中设置。没有新增公共API。

对有限的固定logits，所有被丢项都小于最终最大值减25，胜出者不会被丢弃；实数截断相对误差上界为18710×exp(−25)≈2.59843e−7。这不包含FP32/ExpCore及分母重排舍入误差，不能当作最终分数总误差。

- 相对原版：全位置最大概率差6.02007e−6；实际输出字符最大分数差3.15905e−6；最大行分数差2.39909e−6。行分数在0.80处的穿越为0，不据此保证所有阈值/所有数据均不穿越。
- 对同一CPU FP32 logits的double参考：原版与候选全位置最大绝对误差均4.629643e−5；候选输出位置最大3.818619e−5，重复位置7.376309e−6。旧版自身已有约4.63e−5误差，不能把GPU测试5e−6容差套到CPU总误差。种子重排既可能改善也可能恶化个别分数。
- 英文文章包含在96图中，CPU候选保持原CTC和边界；没有修改之前定位到的GPU FP16排序平局问题。
- 单元测试包括首tile质量、平局、后续/标量尾winner、±1024平移、非有限值、默认关闭和非零矩阵乘的混合batch unit；全库103通过、1个既有设计跳过。netstandard2.0构建成功，保留子模块原有CS0108警告。

## 性能方法与复现

Windows Core Ultra 7 270K Plus，AVX2、24核24线程。通过GetSystemCpuSetInformation的EfficiencyClass识别P核，逻辑编号为0、1、10、11、12、13、22、23。单线程固定CPU0（mask=1），4线程固定不同物理P核0、1、10、11（mask=c03）；在子进程内设置ProcessorAffinity并校验实际mask，DOTNET_PROCESSOR_COUNT分别为1/4。

重放真实GPU主干导出的207份features，每轮覆盖全部20676位置。模型权重与上轮SHA一致。矩阵乘、分母、ArgMax、原有分配/线程调度计入；不计模型加载、解压、GPU主干、裁剪、HTTP和CTC解码，不能当作服务RPS。预分配输入输出，两版各预热至少3秒；同进程显式bool切换，AB/BA反转，每窗口至少10秒并完成整个sweep，先各4对。4核首轮区间包含无收益，因此另保留独立8对确认；不删除首轮。
